🐱 软体猫桌宠测试页面

📋 测试说明

  1. 确保软体猫桌宠扩展已安装并启用
  2. 点击扩展图标查看弹窗界面
  3. 点击"切换软体猫"按钮在页面中显示/隐藏软体猫
  4. 使用快捷键：V键切换调试模式，R键重置软体猫形状
  5. 拖拽洗衣机可以移动整个软体猫系统
  6. 点击"设置"按钮可以调整软体猫的各种参数

  • 软体物理引擎 - 使用 Matter.js 实现真实的软体物理效果
  • 实时渲染 - 基于 Pixi.js 的高性能 2D 渲染

  • 真实贴图 - 使用真实的猫和洗衣机图片

🎮 控制说明

  • 拖拽洗衣机 - 移动整个软体猫系统
  • 按 V 键 - 切换物理网格显示（调试模式）
  • 按 R 键 - 重置软体猫的形状
  • 拖拽软体猫 - 在洗衣机边缘移动软体猫
